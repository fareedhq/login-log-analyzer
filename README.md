# Login Log Analyzer

A Python-based project designed to parse and analyze authentication logs, developed as part of my cybersecurity internship preparation.

## Project Objectives
- **Log Parsing**: Analyze login data to track and calculate successful vs. failed authentication attempts.
- **Python Fundamentals**: Practice core programming concepts including variables, lists, loops, and file handling.
- **Version Control**: Build a consistent habit of tracking progress and managing code through Git.
